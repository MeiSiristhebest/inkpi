# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within InkPi, please do not file a public issue.
Instead, send a responsible disclosure email or create a GitHub Security Advisory.
We appreciate your help in making InkPi safe for creative workers and developers.
